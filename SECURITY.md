# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it via email to:

**contact@aaronburt.co.uk**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof-of-concept.
- Any suggestions for remediation.

All security reports will be reviewed promptly. Please do not open public issues for security vulnerabilities until they have been addressed.
